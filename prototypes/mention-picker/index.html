交互要点@MENTION

01触发

在群聊输入框里输入 @（含中文全角 ＠）即弹层；单聊不触发，避免误打扰。

02检索

继输入的字符即为关键词，同时命中昵称、全拼、首字母：

  • wu → 吴桐 wutong
  • wt → 吴桐（首字母）
  • cjg → 陈建国
  • 张 → 张伟

03键盘

↑↓ 移动高亮，Enter/Tab 选中，Esc 关闭；Enter 不再发送消息。

04插入

选中后替换掉 @关键词，生成蓝色原子片段 @昵称 + U+2005；退格整体删除。

05上行

文本随 msg_type=1 发送，被 @ 成员的 ID 收敛到 payload.at_ids，由服务端换算出 ats。
