01触发

右键或长按消息气泡弹出微信同款菜单：复制 / 转发 / 收藏 / 多选 / 删除。新标记为本次新增能力。

02转发

右键气泡 → 转发，弹出选择器：最近转发头像行 + 三路搜索（昵称 / 全拼 / 首字母，如 zw → 张伟）。单条消息选完人直接发送，普通气泡送达、不包裹卡片。

03转发方式确认

多选消息后无论转发给几个目标，选完人点「发送」都弹出确认页：合并转发打包为一张聊天记录卡片（点开回看快照，原消息删除不影响）；逐条转发以普通气泡逐条送达，非本人消息带「原发送者：」前缀。

04收藏

气泡菜单「收藏」一键入藏；左栏切换到收藏 Tab，支持分类筛选、详情查看、再次转发与删除。

05多选

菜单「多选」进入勾选模式（底栏仅「取消 / 转发」），转发必须经 选择器 → 方式确认 的完整链路；逐条/合并结果形态见 03。

06数据与接口

  • POST /api/messages/forward
  • POST /api/favorites
  • GET  /api/favorites?type=
  • DEL  /api/favorites/:id
  • DEL  /api/messages
  • GET  /api/forwards/recent

全部软删除 · 接口限流复用 risk.py 分档 · 转发卡片消息需 WebSocket 按 id 幂等推送。
